# Modern Deck

Presentation slides written in Markdown with [Marp](https://marp.app/).

## Usage

```bash
npm install
npm run dev       # live preview with auto-reload: http://localhost:8081/slides.md
npm run build     # dist/index.html (static build, also copies assets/)
npm run pdf       # dist/slides.pdf
npm run pptx      # dist/slides.pptx
npm run export    # all of the above
```

> Open `/slides.md` in dev mode. `http://localhost:8081/dist/` is only the
> static output of the last `npm run build` and does not update on its own.
> If changes don't appear, make sure no old dev server is still holding the
> port (`pkill -f "marp --server"`) and hard-refresh the page.

PDF/PPTX export needs Chrome, Chromium, or Edge installed.
You can also edit with live preview in VS Code using the
[Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode) extension.
To make it pick up the custom theme, add to `.vscode/settings.json`:

```json
{ "markdown.marp.themes": ["./themes/modern.css"], "markdown.marp.enableHtml": true }
```

## Presenter mode (speaker notes)

Open the build (`dist/index.html`) or the `npm run dev` page and press **P**
(or the "Presenter" button in the on-screen controls). A window opens showing
the current + next slide and the speaker notes, with `+/−` to zoom the notes.

Speaker notes are plain HTML comments at the bottom of a slide — one comment
per line, one `<p>` per line:

```markdown
# Slide

visible content

<!-- This is the first note line. -->
<!-- And this is the second. -->
```

## Voice-overs

The same note comments are the single source of truth for the audio: the
generator reads them straight from `slides.md` (no separate per-slide text
files). After editing the words:

```bash
python3 mnt/deck/voiceover/render.py am_adam   # dist/voiceover/slide-NN-<heading>.mp3
python3 mnt/deck/voiceover/make-video.py       # dist/deck-video.mp4
```

Stale mp3s in `dist/voiceover/` are pruned and regenerated on each render.
Names are `slide-NN-` + the slide heading slug, so they follow the heading
you choose. (`dist/` is a build-artifact dir — it's gitignored and rebuilt on
demand.)

## Files

- `slides.md` — the deck; slides are separated by `---`
- `themes/modern.css` — custom theme
- `assets/` — images
- `dist/voiceover/` — generated voice-overs (by `voiceover/render.py`)
- `dist/slides/` + `dist/deck-video.mp4` — generated by `make-video.py`
- `voiceover/render.py` — voice-overs from the slide notes in `slides.md`
- `voiceover/make-video.py` — slides + voice-overs → `dist/deck-video.mp4`
- `marp.config.mjs` — Marp CLI config (theme folder, local files, and the `::: class` container syntax used instead of `<div>`)

## Cheatsheet

| Syntax | Effect |
| --- | --- |
| `<!-- _class: lead -->` | Title slide (gradient, centered) |
| `<!-- _class: invert -->` | Dark slide |
| `<!-- _class: invert divider -->` | Section divider |
| `<!-- _paginate: false -->` | Hide page number on this slide |
| `<!-- _header: "" -->` | Hide header on this slide |
| `![bg right:40%](img.png)` | Split slide with image |
| `![bg](img.png)` | Full-bleed background image |
| `* item` | Bullet that reveals step by step (HTML) |
| `<!-- one sentence per line -->` | Speaker note (presenter view) |
| `::: columns` … `:::` | Two columns (`columns three` for three) |
| `:::: stats` ⊃ `::: stat` | Big-number tiles; each tile is `### 15`, a label line, and an optional `*caption*` line (blank lines between them make no difference) |
| `::: card` … `:::` | Boxed content |
| `<!-- _class: quote -->` | Big statement: `> text` (use `**bold**` for gradient emphasis), then an attribution paragraph. Combine with `invert` |
| `:::: compare` ⊃ `::: card before` + `::: card after` | Before → after cards, each starting with a `###` label (blank lines around the markdown inside) |
| `:::: compare plain` | Same as compare but without the arrow, for pros / cons (`card after` = emphasised, `card before` = muted) |
| `<!-- _class: code -->` | Code slide: a fenced block under the title, optional caption paragraph after it. Combine with `invert` |
| `::: steps` + ordered list `1. **Title** text` | Numbered process with connectors (`steps vertical` for a vertical layout) |
| `::: figure` + `![](shot.png)` + caption paragraph | Framed screenshot: rounded border, shadow, centered caption (image is capped at 340px tall) |
| `::: agenda` + ordered list `1. **Section** text` | Agenda with large gradient numbers and divider lines |
| Markdown table | Styled table with a header row and zebra stripes (3–4 columns max) |
| `> text` on a regular slide | Callout box; put it after a paragraph |
| `![bg brightness:0.5 blur:6px](img.png)` | Full-bleed background with filters, so a title stays readable (`brightness`, `blur`, `opacity`, …) |

All of these are shown in `slides.md`.

### Containers

Wrap content in `::: class names` … `:::` instead of raw `<div>` tags. For nesting, give the outer fence more colons (`::::` around `:::`). The config is in `marp.config.mjs`.

## Vertical layout

On titled slides the title stays at the top and the body is centered between
the title and the footer. The header's bottom margin makes the body look low,
so extra space is added below it. Tune it per slide with the
`--body-bottom-space` variable (default `32px`):

```markdown
<style scoped>section { --body-bottom-space: 56px; }</style>
```

Slides with `lead`, `divider` or `quote` are centered on the whole slide.
